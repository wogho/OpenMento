## 에이전트 목록 조회

```bash
GET /api/institutions/:institutionId/agents
```

## 에이전트 생성(배치)

```bash
POST /api/institutions/:institutionId/agents
```

```json
{
  "name": "튜터 에이전트 #1",
  "role": "tutor",
  "skillIds": ["java-spring"],
  "budgetLimit": 1000
}
```

<ResponseField name="id" type="string">에이전트 UUID</ResponseField>
<ResponseField name="name" type="string">에이전트 이름</ResponseField>
<ResponseField name="role" type="string">에이전트 역할</ResponseField>
<ResponseField name="status" type="string">`active` | `paused` | `idle`</ResponseField>

## 에이전트 일시 정지

```bash
POST /api/institutions/:institutionId/agents/:agentId/pause
```

## 에이전트 재개

```bash
POST /api/institutions/:institutionId/agents/:agentId/resume
```

<Warning>
에이전트 생성은 보드 승인 게이트를 통과해야 합니다. 관리자 권한이 필요합니다.
</Warning>
