---
title: Tasks API
description: 작업 관리 REST API
---

## 작업 목록 조회

```bash
GET /api/institutions/:institutionId/tasks
```

<ParamField query="status" type="string">
  `pending` | `in_progress` | `completed` | `failed`
</ParamField>

<ParamField query="agentId" type="string">
  특정 에이전트에 할당된 작업만 조회
</ParamField>

## 작업 생성

```bash
POST /api/institutions/:institutionId/tasks
```

```json
{
  "title": "수강생 A 포트폴리오 피드백",
  "type": "portfolio_review",
  "studentId": "student-uuid",
  "priority": "high"
}
```

## 작업 재할당

```bash
PATCH /api/institutions/:institutionId/tasks/:taskId
```

```json
{
  "agentId": "new-agent-uuid"
}
```

## 작업 취소

```bash
DELETE /api/institutions/:institutionId/tasks/:taskId
```

<Note>
작업 삭제는 `pending` 상태인 작업만 가능합니다. 진행 중인 작업은 취소할 수 없습니다.
</Note>
