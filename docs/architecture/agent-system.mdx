## 에이전트 역할

OpenMento 에이전트는 교육 기관의 직원처럼 역할이 부여됩니다.

| 역할 | 설명 |
|------|------|
| 튜터 | 수강생 1:1 학습 지원, 질의응답 |
| 평가자 | 과제·포트폴리오 진정성 및 품질 평가 |
| 커리큘럼 설계자 | 학습 경로 및 콘텐츠 구성 제안 |
| 운영 담당자 | 일정 조율, 수강생 관리, 리포트 생성 |

## 작업 체크아웃 흐름

에이전트는 작업 큐에서 원자적으로 작업을 체크아웃합니다.

```
[작업 큐] → [예산 잔액 확인] → [원자적 체크아웃] → [작업 실행]
                ↓ 부족
           [체크아웃 거부]
```

<Warning>
예산 없이 작업을 체크아웃하려는 시도는 모두 거부됩니다. 중복 실행 방지를 위해 낙관적 잠금을 사용합니다.
</Warning>

## 스킬 파일

에이전트는 `skills/` 디렉터리의 마크다운 파일을 통해 도메인 지식을 습득합니다.

```
skills/
  java-spring/SKILL.md
  python-django/SKILL.md
```

새 스킬 파일 작성 시:
- 마크다운 형식
- 구체적인 예시와 단계별 지침 포함
- 교육 도메인 컨텍스트 명시
