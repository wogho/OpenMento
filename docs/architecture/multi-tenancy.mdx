## 기관(Institution) 모델

기관은 OpenMento의 최상위 객체입니다. 하나의 인스턴스에서 여러 기관을 독립적으로 운영합니다.

| 필드 | 타입 | 설명 |
|------|------|------|
| `id` | uuid | 기본 키 |
| `name` | string | 기관명 |
| `slug` | string | URL 슬러그 (고유) |
| `settings` | jsonb | 기관별 설정 |
| `createdAt` | timestamp | 생성 시각 |
| `updatedAt` | timestamp | 수정 시각 |

## 격리 규칙

모든 쿼리는 `institution_id`로 스코프를 지정해야 합니다. Row Level Security(RLS) 정책이 DB 레벨에서도 이를 강제합니다.

```typescript
// repositories 레이어에서 항상 institutionId를 포함
export async function getAgents(db: Db, institutionId: string) {
  return db.query.agents.findMany({
    where: eq(agents.institutionId, institutionId),
  });
}
```

## 거버넌스 (V1)

V1에서는 **단일 관리자** 모델을 사용합니다. 보드 승인이 필요한 작업:

- 새 에이전트 배치
- 교육 전략 초기 수립
- 예산 변경

보드 권한 (항상 사용 가능):

- 기관 레벨 예산 설정 및 수정
- 임의 에이전트/작업 일시 정지·재개
- 임의 에이전트 결정 재정의
