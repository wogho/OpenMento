# OpenMento 제품 목표

**OpenMento은 교육 자율 운영의 인프라입니다.** 우리는 교육 현장에서 교강사·수강생·운영자가 직면하는 실질적인 문제를 AI 에이전트 오케스트레이션으로 해결하는 플랫폼을 구축합니다. 목표는 OpenMento 기반의 교육 기관들이 인적 리소스 낭비 없이 높은 수준의 교육 품질을 지속적으로 유지하는 것입니다.

## 비전

AI 에이전트들로 구성된 교육 팀 — 커리큘럼 설계자, 튜터, 평가자, 운영 담당자 — 이 실제 조직처럼 협업하며 교육 기관을 운영하는 시대가 열립니다. 하나의 기관이 아닌 수천 개의 기관이 OpenMento 위에서 구동됩니다.

OpenMento은 교육 기관 그 자체가 아닙니다. **교육 기관을 가능하게 만드는 인프라입니다.** 모든 교육 기관에는 구조, 작업 관리, 비용 통제, 목표 정렬, 거버넌스가 필요합니다. 그것이 우리입니다.

우리의 성공 기준은 하나의 기관이 잘 작동하는 것이 아닙니다. **OpenMento이 자율 교육 기관들이 구축되는 기본 인프라가 되는 것입니다.**

## 핵심 문제

기존 LMS(학습 관리 시스템)는 충분하지 않습니다. 교육 현장 구성원 모두가 AI 에이전트로 보조될 때, 단순한 강의 수강 시스템 이상의 것이 필요합니다 — 교육 기관 전체를 위한 **제어 플랫폼(Control Plane)**이 필요합니다.

### 수강생의 문제

- 모든 학생에게 동일한 커리큘럼과 진도가 적용됩니다.
- 개별 이해도를 반영한 즉각적인 피드백을 받기 어렵습니다.
- AI 도구를 이용한 복붙·양산형 결과물 제출이 만연하여 실제 학습이 이루어지지 않습니다.

### 교강사의 문제

- 수십~수백 명의 수강생에게 개별 피드백을 제공하는 데 과도한 시간이 소요됩니다.
- 학습 이탈 징후를 실시간으로 파악하지 못하고 사후에야 인지합니다.
- 평가의 일관성을 유지하기 어렵고, 과제의 진정성 검증에는 한계가 있습니다.

### 교육 운영자의 문제

- 수강생 관리, 일정 조율, 리포트 생성 등 반복적인 운영 업무에 리소스가 낭비됩니다.
- 교육 성과 데이터가 분산되어 있어 의미 있는 인사이트 도출이 어렵습니다.
- 에이전트 운영 비용을 통제하는 체계가 없습니다.

## OpenMento이 하는 일

OpenMento은 AI 에이전트들로 구성된 교육 팀의 지휘·통신·제어 플랫폼입니다. 단일 플랫폼에서 다음을 수행합니다:

- **에이전트를 교육 직원으로 관리** — 배치, 조직, 업무 추적
- **조직 구조 정의** — 에이전트들이 실제로 운영하는 조직도
- **작업을 실시간으로 추적** — 현재 어떤 에이전트가 무엇을 하고 있는지 확인
- **비용 통제** — 에이전트별 토큰 예산, 지출 추적
- **목표 정렬** — 에이전트가 자신의 작업이 더 큰 교육 미션에 어떻게 기여하는지 인식
- **양산형 포트폴리오 방지** — 벡터 유사도 분석으로 모방 및 복붙 결과물을 구조적으로 탐지
- **교육 지식 저장** — 기관의 공유 지식 베이스 (RAG 파이프라인)

## 아키텍처 원칙

두 개의 레이어:

### 1. 제어 플랫폼 (이 소프트웨어)

중앙 신경계입니다. 다음을 관리합니다:

- 에이전트 레지스트리 및 조직도
- 작업 할당 및 상태
- 예산 및 토큰 지출 추적
- 교육 지식 베이스 (RAG)
- 목표 계층 (기관 → 팀 → 에이전트 → 작업)
- 하트비트 모니터링 — 에이전트의 활성·유휴·오류 상태 파악

### 2. 실행 서비스 (어댑터)

에이전트는 외부에서 실행되고 제어 플랫폼에 보고합니다. 어댑터는 다양한 실행 환경을 연결합니다:

- **Claude / GPT-4o / Gemini** — LLM API 기반 어댑터
- **Ollama** — 로컬 LLM 자체 호스팅 어댑터
- **HTTP API** — 커스텀 에이전트 REST 엔드포인트
- **MCP** — Model Context Protocol 지원 에이전트

제어 플랫폼은 에이전트를 실행하지 않습니다. 에이전트를 오케스트레이션합니다.

## 핵심 원칙

OpenMento을 보면 전체 교육 기관을 한눈에 이해할 수 있어야 합니다 — 누가 무엇을 하고 있는지, 얼마나 드는지, 그리고 실제로 작동하고 있는지.
